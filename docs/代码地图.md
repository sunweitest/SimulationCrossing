# 代码地图

> 目的：改一个功能时能**一次找对文件**。按「功能 → 前端 → 接口 → 后端 → 数据 → 配置」排列。
> 行号会漂移，所以定位一律用函数名/关键字，最后附了常用 grep。

## 1. 一图看整体

```
浏览器
  └─ nginx:8080        frontend/dist（Vue3 SPA） + /api 反代
       └─ uvicorn:8000  FastAPI
            ├─ middleware/rate_limit.py   次数限制（每次行动前检查、成功后计数）
            ├─ api/*.py                   路由层：鉴权、归属校验、组装响应
            ├─ services/game_service.py   业务编排：拼消息、调 LLM、存场景、算积分
            ├─ services/llm/*.py          LLM 适配（DeepSeek / DashScope）
            ├─ services/scene_image_matcher.py  场景图匹配（阿里云 embedding）
            └─ PostgreSQL（内容/存档） + Redis（次数计数）
```

## 2. 前端

| 文件 | 职责 | 关键内容 |
|---|---|---|
| `frontend/src/router/index.js` | 路由表 | `/`（跳转）、`/login`、`/register`、`/character-create`、`/game/:id?`、`/my-games`、`/character-relations`、`/admin`；守卫：`requiresAuth`、`requiresGame` |
| `frontend/src/api/index.js` | 所有 HTTP 封装 | `authAPI` / `gameAPI` / `adminAPI` 三组，axios 拦截器在这里挂 token |

| `frontend/src/views/GameView.vue` | 游戏主界面（最常改） | 顶栏（含 `quota-stat` 剩余次数徽标）、行动按钮、自定义行动、错误 toast、**次数用完弹窗**（`showQuotaModal`）、**回合回溯面板**（`openTurns`/`doRewind`、`.turns-modal`）、侧边栏角色信息 |
| `frontend/src/views/CharacterCreateView.vue` | 选世界 → 选角色 → 建会话 | 世界卡片、预设角色、自定义角色表单 |

| `frontend/src/views/CharacterRelationsView.vue` | 人物关系图 | 关系/好感度展示 |
| `frontend/src/views/AdminView.vue` | 管理后台（1075 行，单文件） | 登录门禁（`X-Admin-Key`）、用户管理、小说/时间线/预设角色 CRUD、角色模板导入 |
| `frontend/src/components/AuthModal.vue` | 登录/注册弹窗 | 被 `CharacterCreateView` 使用，登录后**停留在原页**（不跳转）；表单与 `LoginView`/`RegisterView` 各是独立一份，改校验/文案要**三处同步**；`?redirect=` 回跳只在 `LoginView`/`RegisterView` 里有 |

## 3. 后端接口（`backend/app/api/`）

### game.py — 玩家侧（`/api/game`）

| 接口 | 作用 | 函数 |
|---|---|---|
| `GET /characters`、`GET /novels` | 选人/选世界的数据源 | — |
| `GET /quota` | 今日次数（`is_guest/daily_limit/used_today/remaining/login_limit`） | `get_my_quota` |
| `POST /session` | 新建对局（游客也可建，`user_id` 为空） | `create_session` |
| `POST /action` | 非流式行动（返回结构化 `Scene`） | `perform_action` |
| `POST /action/stream` | **前端实际用的**，SSE 推剧情 → 选项/积分 | `perform_action_stream` |
| `GET /session/{id}` | 读存档 | `get_session` |
| `GET /session/{id}/state`、`/characters`、`/character/{name}` | 对局内状态、人物列表、单人物详情 | — |
| `GET /sessions` | 我的存档列表（**要登录**） | `list_sessions` |
| `DELETE /session/{id}` | 删存档 | `delete_session` |

> 归属规则：`_claim_anonymous_session()` —— 已登录用户访问 `user_id IS NULL` 的会话时自动认领，登录前的进度才不会丢。四个入口都调了它。

### auth.py — `/api/auth/register`、`/login`，返回 `access_token` + `user`

### admin.py — `/api/admin/*`
`X-Admin-Key` 头 + `settings.ADMIN_KEY` 比对（不是账号体系）。
用户：`/lookup`、`/users`（列表+搜索+分页）、`/add-quota`、`/monthly-unlimited`（POST/DELETE）
内容：`/novels`、`/timelines`、`/characters` 的 CRUD；`/character-template`（xlsx 模板）、`/character-import`

## 5. 常见改动怎么下手

| 想改什么 | 动哪里 |
|---|---|
| 回合回溯 / 分支重开 | `api/game.py` 的 `list_turns()` / `rewind_session()` + `GameView.vue` 的 `openTurns()` / `doRewind()`；历史带 `turn_index` |
| 行动选项数量 | `.env` 的 `CHOICE_COUNT`（提示词、解析、补齐三处都读它） |
| 时区 / 时间格式 | `app/core/timeutil.py` 的 `now_cn()`（全站北京时间，库里存 naive 本地时间） |
| 数据库备份 | `/usr/local/bin/simcrossing-backup.sh` + `/etc/cron.d/simcrossing-backup`（每天 03:30，保留 14 天） |
| 每日免费次数 / 登录后额度 | `.env` 的 `DAILY_FREE_MESSAGES`、`DAILY_LOGGED_IN_EXTRA`（**不用改代码**） |
| 次数用尽的提示/弹窗 | `GameView.vue`：`showQuotaModal`、`QQ_NUMBER`、`.quota-modal*` 样式；游客分支仍是 `.error-toast` |
| 次数规则本身（按 IP/按设备/白名单） | `services/quota.py` + `middleware/rate_limit.py`，两处必须同步 |
| 顶栏「剩 N 次」徽标 | `GameView.vue` 的 `quota` / `quotaTitle` / `loadQuota()` |
| 换模型、网关、开/关思考 | `.env`：`DEEPSEEK_MODEL`、`DEEPSEEK_PRO_MODEL`、`DEEPSEEK_BASE_URL`、`DEEPSEEK_DISABLE_THINKING` |
| 剧情风格 / 系统提示词 | `deepseek_provider.py` 的 `_select_system_prompt()` 系列 + 顶部各 `*_SYSTEM_PROMPT` 常量 |
| 行动选项数量/格式 | `generate_scene_metadata()`、`_parse_metadata()`、提示词里的 JSON 约定 |
| 场景配图 | `scene_image_matcher.py` + 图片放 `frontend/public/images/scene/`（缓存 `backend/cache/scene_embeddings.json`） |
| 积分/成就规则 | `game_service.py`（`points_awarded`、`new_achievement`）+ `deepseek_provider._parse_metadata()` |
| 管理后台加字段/列表 | 先 `api/admin.py`，再 `AdminView.vue` + `api/index.js` 的 `adminAPI` |
| 新增接口 | `api/game.py` 加路由 → `api/index.js` 加方法 → 页面调用；注意是否要在 `rate_limit.py` 里算次数 |
| 注册同意条款 | 前端 `RegisterView.vue` + `components/AuthModal.vue` 两处勾选框 → 后端 `api/auth.py` 校验 `agree_terms` → 写 `users.terms_accepted_at` |
| 合规文本（隐私/条款/退款） | `frontend/src/content/legal.js`（运营者、邮箱、日期都在顶部 `LEGAL_META`）→ `views/LegalView.vue` 渲染 `/privacy` `/terms` `/refund` |
| 登录态/权限 | `stores/auth.js`、`api/deps.py`（`get_current_user` / `get_current_active_user`） |

## 6. 配置速查（`.env`）

| 键 | 作用 |
|---|---|
| `DEEPSEEK_MODEL` / `DEEPSEEK_PRO_MODEL` | 主模型 / 压缩模型 |
| `DEEPSEEK_BASE_URL` | 网关地址（模型名非官方命名时必须同时改） |
| `DEEPSEEK_TEMPERATURE` / `DEEPSEEK_MAX_TOKENS` | 创造性与输出上限；推理模型的 reasoning 也吃 max_tokens |
| `DEEPSEEK_DISABLE_THINKING` | 关闭思考（默认 true）：更快、避免空响应 |
| `DAILY_FREE_MESSAGES` / `DAILY_LOGGED_IN_EXTRA` | 游客额度 / 登录后额外额度 |
| `USE_QWEN_METADATA` | 选项/积分是否走 Qwen（默认 false，走 DeepSeek） |
| `DASHSCOPE_API_KEY` | 场景图匹配用（阿里云 embedding）；**不配则不启用配图** |
| `ADMIN_KEY` | 管理后台密钥 |
| `SECRET_KEY` | JWT 密钥 |
| `CONTEXT_COMPRESSION_THRESHOLD` / `CONTEXT_RECENT_TURNS` | 何时压缩历史、压缩后保留几轮 |

Redis key 一览：`rate_limit:guest:ip:<ip>:<日期>`、`rate_limit:user:<id>:<日期>`、`rate_limit:user:<id>:extra`、`rate_limit:user:<id>:unlimited`

## 7. 快速定位（复制即用）

```bash
# 某个页面元素在哪
grep -rn "quota-modal\|quota-stat" frontend/src
# 某个接口谁在用
grep -rn "/game/action/stream" frontend/src backend/app
# 文案在哪
grep -rn "次数已用完\|前往登录" frontend/src backend/app
# 模型调用点（改模型/参数必须全改）
grep -rn "chat.completions.create" backend/app
# 配置项被谁读
grep -rn "settings.DAILY_FREE_MESSAGES" backend/app
```

## 8. 改动后的验收口径

1. 后端：`systemctl restart novel-backend` → `curl /health` → 打一次 `/api/game/action`（非流式）与 `/api/game/action/stream`（流式）都要 200 且有正文
2. 前端：`npm run build`（**必须用 `www-data` 用户跑**）→ 刷新页面看真实 DOM，不只看接口
3. 次数相关：Redis 里 `rate_limit:*` 有值、顶栏数字随行动变化、游客 429 出 toast、登录用户 429 出弹窗
4. 别在有人正在玩的时候 `redis-cli DEL rate_limit:*`，会把当日额度清空
