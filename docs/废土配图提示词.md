# 废土世界配图提示词（Prompt Pack）

> 用途：《AI穿越模拟》废土末世世界的封面图 + 场景配图。
> 现状：`frontend/public/images/scene/` 里 25 张全是三国/水浒的古装战争图，
> 废土场景现在会被匹配到古装图。这批图补上后匹配才准。

---

## 一、统一风格锚（每条提示词都带上）

**中文描述段**（给即梦 / 通义万相 / 豆包 / 可灵这类中文模型）：

```
电影感末世概念设定图，废土荒原题材，写实厚重的环境质感。
色调：冷灰蓝与铁锈橙对比，点缀暗黄绿；低饱和、去饱和处理。
氛围：空气中有浮尘与烟雾，斜射的体积光，远处地平线被尘霾吞没。
画风：35mm 电影镜头质感，浅景深，轻微胶片颗粒与暗角，超广角环境全景。
构图：16:9 宽画幅，主体位于画面中下部，上方留出天空与远景层次。
禁止：任何文字、水印、logo、界面元素、卡通或二次元风格。
```

**英文 tag 段**（给 Midjourney / SD / Flux）：

```
cinematic post-apocalyptic concept art, desolate wasteland, grounded realism,
muted desaturated palette, cool steel-blue shadows with rust-orange highlights,
faint sickly-green haze, airborne dust and volumetric god rays,
distant horizon swallowed by smog, 35mm film look, shallow depth of field,
subtle film grain and vignette, ultra wide establishing shot,
16:9 composition, subject in lower middle third, layered sky and background,
ultra detailed environment, high dynamic range, no text, no watermark, no UI
```

**通用负面提示词**：

```
text, letters, watermark, logo, signature, UI, HUD, border, frame,
cartoon, anime, cel shading, toy, 3d render look, oversaturated, neon pop,
lowres, jpeg artifacts, blurry, deformed hands, extra limbs, fused fingers,
duplicate subject, crowd of identical people, modern smartphone
```

**一致性技巧**：先生成封面，把封面作为 **style reference / 参考图**（MJ 用 `--sref`，SD 用 img2img 或 IP-Adapter，即梦用"参考风格"），再批量生成场景图；同一批固定同一个 `--seed`。

## 四、参数建议

| 工具 | 参数 |
|---|---|
| Midjourney | `--ar 16:9 --style raw --s 200 --v 7`，固定 `--seed`；封面做完用 `--sref` 统一风格 |
| Flux / SDXL | 1536×864 或 2732×1534（与现有图一致）；Flux steps 28–32 / CFG 4.5；SDXL steps 30 / CFG 7 / DPM++ 2M Karras |
| 即梦 / 通义万相 / 豆包 | 直接贴中文描述，比例 16:9，负面词单独填，风格选"写实 / 电影感" |
| 可灵 / 混元 | 中文描述 + 16:9，"电影质感"权重拉高 |

**通用提醒**：

- 别让人物正脸占太大——AI 生成的脸容易崩，而这是背景图，剪影和背影更安全
- 生成后统一压暗 10–15% 并加一点噪点，和现有古装图放一起不会显得"太亮太新"
- 一定检查有没有糊字、假 logo，这类瑕疵在图里格外扎眼

## 五、放进项目（3 步）

1. **场景图**：存成 PNG，放到 `frontend/public/images/scene/`，文件名用上面的中文名（**文件名就是这个图的语义**，匹配器把它做成向量跟剧情描述比对）。
2. **缓存不用手动删**：图片数量变化时后端会自动重建 `backend/cache/scene_embeddings.json`，然后重启：

   ```bash
   sudo systemctl restart novel-backend
   ```

3. **封面**：主图替换 `images/wasteland.png`（1600×900），再生成缩略图（400×225）：

   ```bash
   cd /opt/novel/SimulationCrossing
   /opt/venv/bin/python -c "from PIL import Image; Image.open('images/wasteland.png').convert('RGB').resize((400,225), Image.LANCZOS).save('frontend/public/images/covers/wasteland.webp','WEBP',quality=80)"
   ```

   venv 里没装 Pillow 的话：`uv pip install --python /opt/venv/bin/python pillow`

**验收**：玩一局废土，看后端日志有没有
`MATCH: score=0.4xx file=辐射尘中的城市废墟.png` —— 出现废土图文件名就对了。
